# Configuración de dominio

`risk_matrix.v1.json` es la matriz didáctica versionada del prototipo. Incluye exactamente una regla para cada categoría canónica, con identificador único, condiciones orientativas, urgencia recomendada, departamento y evidencia breve.

El documento se valida con contratos Pydantic antes de devolver una observación. Cambiar su estructura o catálogo exige una nueva versión y pruebas.

No contiene normativa profesional: sus recomendaciones no sustituyen la evaluación de riesgos, la decisión del técnico ni el protocolo de emergencias.
